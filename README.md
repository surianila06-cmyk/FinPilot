# Prospera

**AI-powered personal financial assistant**

Prospera helps users understand their financial information and receive personalized guidance for budgeting, loans, savings, and financial goals.

## MVP Features

- Upload financial documents such as payslips
- AI-powered financial information extraction
- Automatic financial profile generation
- Financial health scoring
- AI financial advisor
- Budget and loan analysis
- Gold and financial goal planning
- Agent-based financial planning

## How It Works

```text
Financial Document
        ↓
   PDF Extraction
        ↓
      Groq AI
        ↓
 Financial Profile
        ↓
 Financial Analysis
        ↓
   Planner Agent
        ↓
 Personalized Guidance
```
## Tech Stack
- Frontend: React / Next.js
- Backend: Python, FastAPI
- AI: Groq, Llama
- Database/Services: Firebase
- Deployment: Vercel + Render
